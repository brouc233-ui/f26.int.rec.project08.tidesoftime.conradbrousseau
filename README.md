# Tides of Time

A p5.js ocean clock for Conrad Brousseau's **Core 1: Interactions** class,
November 2026.

Choose California, New York, London, the Maldives, or Tokyo to see its current
time. The moving blue lines are waves; the hands show hours, minutes, and
seconds.

## Open the clock

Open `index.html` in a browser. An internet connection is needed to load p5.js
and the fonts.
